# 📊 Análise dos Microdados do ENEM 2019 (Ceará)

Este projeto tem como objetivo analisar os microdados do ENEM 2019, com foco nos candidatos do estado do Ceará. A análise inclui:

- Identificação de faltantes e presentes
- Análise de notas por sexo, raça, tipo de escola e renda
- Modelos preditivos para prever faltas e notas
- Visualizações estatísticas
